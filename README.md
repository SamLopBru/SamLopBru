## 🚀 Selected Projects  

- [:mag_right: **Breast Cancer Detection using Deep Learning**](https://github.com/SamLopBru/FinalDegreeProject.git)  
  Developed a CNN with a slice-level attention mechanism to improve diagnostic accuracy in 3D tomosynthesis mammography.
  
- [🧠 **Transformer-Based White Matter Tractography Segmentation**](https://github.com/SamLopBru/TractographyClassificationThesis.git)  
  Developed a deep learning pipeline for automated white matter tract segmentation using normalized spherical-coordinate representations of tractography streamlines. Benchmarked recurrent neural networks and Transformers, exploring supervised contrastive pretraining and focal loss. Evaluated on the multicenter TractoInferno dataset, achieving a **91.85% Macro F1-score and 2.91% Expected Calibration Error**. **Ongoing research focuses on refining the approach and preparing the work for scientific publication.**

- [🔬 **Tissue Classification in Histological Colorectal Images**](https://github.com/SamLopBru/ColorrectalDL.git)  
  Built a deep learning pipeline using VGG19, ResNet50, and InceptionV3 to classify 8 tissue types, achieving **94.2% accuracy**.
